# DiffSpot

**Can VLMs Detect Visual Changes in Web Pages?**

[![Dataset](https://img.shields.io/badge/🤗_Dataset-TBD-yellow)](TBD)

DiffSpot is a benchmark for **visual change detection in real-world web UIs**. Given two screenshots of a web page that differ by one or more programmatic HTML/CSS mutations, a VLM must describe **all** the differences. Ground truth is generated by recording the mutation operators applied to the source HTML — no human annotation in the loop.

> 🚧 **Dataset and paper release pending.** This repository ships the full evaluation stack (judge, metrics, baseline runners, CI, tests). Once the DiffSpot dataset is published on HuggingFace, set `diffspot.data.HF_DATASET_ID` to the published id and the Quick Start below becomes runnable end-to-end. Until then the test suite (`pytest -v tests/`) exercises the eval pipeline against synthetic data, with no API key or dataset download required.

## Highlights

- **3,900 has-diff pairs + 500 no-diff pairs** = **4,400 evaluation instances**, URL-globally-unique
- **13 CSS-property-level operators** in 4 families: typography (`font_weight` / `font_size` / `letter_spacing` / `line_height` / `text`), color (`color` / `opacity` / `gradient`), layout (`position` / `spacing` / `justify`), shape (`border` / `rounded`)
- **3 difficulty tiers** (Easy / Medium / Hard) — 39 balanced cells of 100 pairs each (13 operators × 3 tiers)
- **Programmatic GT** — zero hand annotation, fully reproducible pipeline
- **Grounding-gate validation** — every pair anchored to the target element's bounding box, rejecting no-effect and reflow-contamination failures
- **Open-ended description format** + **no-diff hallucination control**
- **LLM-as-Judge** (prompt published in the paper appendix and in [`diffspot/prompts/judge.txt`](diffspot/prompts/judge.txt))

**Headline finding**: Gemini 3.1 Pro leads at **47.2% Overall Accuracy** — 5.0 pp ahead of Kimi K2.5 (42.2%) and 32 pp above InternVL3.5-30B-A3B (15.0%). Seven of thirteen models fall below 30% Accuracy, and even the leader misses three of every five ground-truth mutations (Diff Overall Recall ≈ 41%). The top-4 non-conservative models all lose 34–38 pp Recall going from Easy to Hard, and Hard-tier Recall stays below 23% for every model. Open-ended Visual Diff Detection on real web-UI pairs is not solved.

## Quick Start

```bash
git clone https://github.com/<org>/DiffSpot.git
cd DiffSpot
pip install -e ".[api]"

export OPENAI_API_KEY=...   # for both the baseline run and the judge

# 1. Run a baseline VLM (uses HF dataset, writes predictions JSONL)
python baselines/api/run_openai.py \
    --model gpt-5.4 \
    --output results/gpt-5.4/predictions.jsonl

# 2. Score predictions with the official LLM judge (gpt-oss-120b via OpenAI)
python scripts/evaluate.py \
    --predictions results/gpt-5.4/predictions.jsonl \
    --judge-model gpt-oss-120b \
    --output results/gpt-5.4/scores.json

# 3. Print the official metrics table
python scripts/show_results.py results/gpt-5.4/scores.json
```

To target an OpenAI-compatible endpoint (vLLM, sglang, an internal gateway) for the judge, set `OPENAI_BASE_URL`. Anthropic / Google baselines use their respective env vars (`ANTHROPIC_API_KEY`, `GOOGLE_API_KEY`).

# Examples

A small, self-contained walkthrough of the DiffSpot evaluation flow.

## Files

- `walkthrough.ipynb` — load a few items, run a baseline, score with the judge (TBD)
- `sample_predictions.jsonl` — 10 example predictions from each split, with judge labels
- `sample_screenshots/` — 5 (image_a, image_b) pairs covering different mutation types

These files are sized to fit in the repo (tiny) and are intended for demos, not for evaluation. The full benchmark lives on HuggingFace.
